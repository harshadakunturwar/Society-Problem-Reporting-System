# Society Problem Reporting System

A centralized web application designed to help residents report common problems in their housing society (water leakage, lift issues, garbage, streetlights, security, and maintenance).

## Features
- **User-Friendly Complaint Form**: Submit issues with specific categories and descriptions.
- **Upvote Mechanism**: Support existing complaints to prevent duplicates and highlight high-impact problems.
- **Priority Sorting**: Automatically sorts complaints based on vote counts.
- **Status Tracking**: Committee dashboard tags issues as *Pending*, *In Progress*, or *Resolved*.

## Tech Stack
- **Frontend**: HTML5, CSS3, JavaScript
- **Storage**: LocalStorage (Prototype implementation) / MySQL / Firebase Ready
